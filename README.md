# Skill Bridge Community — Website

Official website of **Skill Bridge Community (SBC)** at ISIMG.

The website presents the club, its activities, events, objectives, and ways for students and professionals to get involved.

## Technologies

* HTML
* CSS
* JavaScript

## Purpose

The website serves as the club's online presence and helps connect students with academic and professional opportunities.
